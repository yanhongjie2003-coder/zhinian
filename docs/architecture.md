# 架构与代码导读

> 止念是纯原生 HTML / CSS / JavaScript,零依赖、零构建。
> 代码按「**一个页面一个文件、一个效果一个文件**」拆开,每个文件只做一件事,并配了中文注释。

## 页面一览(6 屏 + 2 弹层)

| Tab / 入口 | 内容 |
|---|---|
| 记录 | 今日总览 + 念头卡片,点卡片即 +1(可撤销) |
| 统计 | 日/周/月/年四种视图 + 各念头分布 |
| 念头 | 念头管理(暂停/详情);**右上角按钮 → 归档**(添加在右下角悬浮钮) |
| 设置 | 主题三选 · 备份/恢复 · 导出/导入 · 测试数据导入 · 重置数据 |
| 归档 | 从念头页右上角进入;已归档念头列表,点圆钮恢复,数据一直在 |
| 详情 | 从念头页/归档页进入;**改名(铅笔)、归档/恢复、删除、单条记录删除** |
| 弹层 | 添加念头、重命名、危险操作确认窗 |

## 数据是怎么存的

```
内存(thoughts + records) ←—— 所有页面渲染都只读这里
   ↑ 启动自动载入               ↓ 每次变化自动保存(刷新/关页面不丢)
     localStorage「zhinian.data」←—— 自动保存,主存储
     localStorage「zhinian.snapshot」←—— 手动备份,设置页可回滚
   导出 → 下载 .json 文件(可换机)      导入 ← 选择 .json 文件
危险操作(恢复备份/导入/测试数据/重置)都先弹确认窗,确认后才动内存。
```

- **自动保存**:计数、撤销、添加、暂停、归档、导入……每次数据一变就写进
  本机 localStorage,刷新或关闭浏览器再打开,数据原样回来;
- **首次使用是干净的空状态**,测试数据只从设置页「测试数据导入」手动载入;
- 「备份到本机 / 从备份恢复」是手动快照,用于大胆操作前留后路;
- 「导出」的 .json 文件可以换设备,「从文件导入」装回来;
- 导入时逐条校验,格式不对的行会被丢弃,不会弄崩页面。

## 代码是怎么串起来的

```
02-data.js          03-stats.js           04-charts.js
生成原始数据   →    把数据算成数字   →    把数字画成图表
(念头+记录)       (今天几次?连续几天?)   (条形图/折线图/热力图)
                                            ↓
       16-app.js(总调度)  ←  05~10-page-*.js(每个页面各一个文件,负责拼自己的HTML)
       用户点了什么/切到哪页,就调用哪个页面文件重新渲染
```

一句话:**页面文件只管"画",stats 只管"算",storage 只管"存取",data 只管"生成",app.js 只管"调度"。**

## 想改点什么?从哪个文件下手

| 你想改的 | 去改哪个文件 |
|---|---|
| 配色、深色模式颜色 | `css/01-tokens.css` |
| 首页卡片的样子 | `css/04-page-home.css` |
| 改某句话文案 | `js/05~10-page-*.js` 里搜文字 |
| 改测试数据的规律 | `js/02-data.js` 的 `loadDemoData()` |
| 加一种新图表 | `js/04-charts.js` 加一个函数,再在页面文件里调用 |
| 改保存/导入的格式 | `js/09-storage.js` |
| 改点击后的行为 | `js/13-counter.js`(计数)、`js/16-app.js`(其他点击) |
| 加一个新页面 | ① `index.html` 加一个 `<section class="screen">` ② 新建 `js/xx-page-xxx.js` 写渲染函数 ③ 在 `16-app.js` 的 `showScreen` 里登记 |

## 与原单文件版的对应关系

`docs/prototype.html` 是最初的**单文件原型**(留档)。这里的代码与它逐段对应、逻辑一行没少,此外做了这些调整:

1. **去掉了宣传版式**:删掉左侧产品说明栏、顶部跳转工具栏、手机外壳、状态栏、底部手势条——只保留 App 界面本身;
2. **新增设置页**(原版没有):主题三选、备份/恢复、导出/导入、测试数据导入、重置数据,破坏性操作均带确认窗;
3. **数据自动保存**:每次数据变化自动写入本机 localStorage,启动时自动载入;
4. 深色模式**跟随系统**(可在设置页改),URL 参数可临时强制;
5. **修了 3 个原版就有的 bug**:① 顶部工具栏按钮点击无效;② 点暂停开关会同时误开详情页;③ 暂停/添加/归档后的提示条也带"撤销"按钮,点了没东西可撤还会跳回首页;
6. **清掉了全部死代码**:没人用的样式/图标/字段——现在图标、样式与页面一一对应;
7. 全部功能已按 [testing-report.md](testing-report.md) 逐项实测通过。
