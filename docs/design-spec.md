# 「止念」念头计数器 · V1.0 初版设计文档

> 一句话定位:**不与念头对抗,而是数它、看见它。**
> 每当"不想要的念头"浮现,打开 App 轻点一次;App 在本地保存记录,用日 / 周 / 月 / 年的可视化让你直观看见它的出现频率。

---

## 1. 产品理念与设计原则

这个想法背后是心理学中的**白熊效应**(越告诉自己"别想",念头越反弹)。压抑不可持续,但**觉察可以**。正念练习中的"标记"(noting)正是如此:念头升起时,不评判、不跟随,只是认出它、记下它。因此本产品把"计数"定义为**觉察**,而不是失败记录。

设计原则(所有屏幕必须遵守):

1. **零摩擦计数** —— 从解锁到完成一次记录 ≤ 2 秒:首页即计数页,点卡片一下就是 +1。
2. **无羞耻感** —— 不用红色/警告/失败字样;文案永远是"觉察了几次",不是"破戒几次"。绿色(正念绿)留给进步与连续天数。
3. **只看见,不评判** —— 数据是镜子不是考卷;波动是正常的,趋势交给图表自己说话。
4. **绝对隐私** —— 全部数据本地存储(Room),无账号、无上传、离线可用。
5. **误触可救** —— 每次计数后 5 秒内可撤销(Snackbar),不弹确认框打断主流程。

## 2. 核心用户流程

```
首次启动 → 引导页(1 屏)→ 添加第一个"约定" → 空状态首页
日常使用 → 念头浮现 → 打开 App → 轻点对应卡片(+1,震动+动画)→ 关掉 App(可选:瞄一眼趋势)
回顾 → 统计页(日/周/月/年切换)→ 看见频率与趋势 → 念头详情看单条约定全貌
```

引导只做一件事:把"不要想/不要做的事"写下来成为一条**约定**(示例:"不要想过去的事""不要抱怨")。预设 chips 让用户 10 秒完成。

---

## 3. V1 功能范围

**做(MVP):**
- 约定管理:添加 / 重命名 / 暂停(不删数据)/ 归档;预设建议 chips
- 一键计数 + 撤销;每次记录存精确时间戳
- 统计:今日概览、周条形图、月折线图、年日历热力图、各念头分布、较上期变化
- 念头详情:单个约定的全维度统计 + 最近记录时间线
- 深色模式;完全离线

**明确不做(V1.1+ 再议):**
- 备注/触发场景记录(违背零摩擦,改为详情页对单条记录补记)
- 桌面小组件、通知提醒、习惯养成课程、云同步、社交、成就徽章

## 4. 信息架构与导航

底部导航 3 个 Tab(≤5,符合规范):

| Tab | 名称 | 内容 |
|---|---|---|
| 1 | **记录** | 今日总览 + 约定卡片列表(整卡 = 计数按钮) |
| 2 | **统计** | 日/周/月/年分段切换 + 分布 + 趋势注解 |
| 3 | **念头** | 约定列表管理 → 进入念头详情 |

次级页面:念头详情(自念头 Tab 或统计图点击进入,带返回)、添加念头(底部弹层)。返回行为遵循 Android 系统返回,弹层优先关闭。

## 5. 屏幕规格

### 5.1 记录(首页)
- 顶部:日期 + 主文案「此刻,浮起了什么念头?」
- 今日总览条:今日觉察 **N** 次(大号衬线数字)· 连续觉察 M 天(火苗图标,正念绿)
- 约定卡片(每条约 96dp 高,整卡可点,点击区远超 48dp):
  - 左:圆形符号(约定首字,底色为该约定专属色 12% 透明度)
  - 中:约定名称 + 「今日 n 次 · 本周 m 次」+ 7 日迷你走势(sparkline)
  - 右:「+1」圆钮(56dp,主色)
  - 点击反馈:涟漪 + 数字 pop(240ms, spring);真机叠加触觉震动
  - 点击后 Snackbar:「已觉察 1 次 · 撤销」(5s)
- 空状态:云朵图标 + 「写下一个你想放下的念头」+ 添加按钮

### 5.2 统计
- 分段控件:日 / 周 / 月 / 年(单选,切换下方主图)
- 摘要行(随范围变化):范围内总次数 · 日均 · 较上期 ±%(周比上周、月比上月、年比去年;文案中性,不加好坏色,仅方向箭头)
- 主图卡(选型依据图表检索结论):
  - **日**:今日大数字 + 各念头今日分布横条
  - **周**:7 天条形图(今日柱高亮主色,其余淡紫;柱顶数值)
  - **月**:30 天折线 + 20% 透明面积图,首尾点标注
  - **年**:365 格日历热力图(≤365 格,符合 SVG 上限),5 档紫色阶 + 「少→多」数值图例
- 「都是什么念头」:各念头横向条形(颜色 + 数值标签,不单靠颜色传达)
- 底部固定一句安抚文案:「每一次记录,都是一次觉察。」

### 5.3 念头(管理)
- 列表:符号圆 + 名称 + 累计次数 + 启用/暂停开关;点击行进详情
- 右上「+」打开底部弹层:名称输入 + 6 个建议 chips + 「添加约定」主按钮

### 5.4 念头详情
- 头部:返回 + 符号 + 名称 + 累计总数 / 记录天数
- 周条形图 + 年热力图(复用统计组件)
- 最近记录时间线(日期 + 时刻,最近 6 条)
- 「归档此约定」次要按钮(红字仅用于此类破坏性操作)

## 6. 数据模型(本地 Room)

```sql
Thought(id INTEGER PK, name TEXT, colorIndex INT, createdAt INT,
        paused INT DEFAULT 0, archived INT DEFAULT 0)
Record(id INTEGER PK, thoughtId INT FK->Thought, timestamp INT)  -- 每行 = 一次觉察
```
统计全部由 SQL 聚合按天/周/月/年分组派生;概念上"周一起始"跟随系统 locale(中国周一开始)。

## 7. 设计系统(源自 ui-ux-pro-max 检索:极简/瑞士风,calm lavender + mindful green)

| Token | Light | Dark | 用途 |
|---|---|---|---|
| --primary | #7C3AED | #A78BFA | 主操作、高亮柱、选中态 |
| --accent | #059669(文字用 #047857) | #34D399 | 连续天数、进步、正向 |
| --bg | #FAF5FF | #16141D | 页面背景(薰衣草微染) |
| --card | #FFFFFF | #1F1B29 | 卡片 |
| --text | #0F172A | #F2EFFA | 主文本(两模式均 ≥4.5:1) |
| --muted | #475569 | #A9A3BC | 次文本 |
| --border | #EFE7FC | #2C2739 | 描边分隔 |
| --danger | #DC2626 | #F87171 | 仅删除/归档 |
| 约定色 | --t1~t4 紫/青/琥珀/玫红(暗色换亮版) | | 各约定专属色 |

- 字体:数字与标题 **Lora**(衬线,日记般的平静感);正文 **Noto Sans SC**(Android 上回退系统中文)。
- 圆角:卡片 20dp、按钮全圆;间距 8dp 节奏,页边距 20dp;图标统一 Lucide 风格、1.75 描边、24dp 栅格。
- 动效:按压 80–150ms 内给反馈;数字 pop 240ms spring;列表入场上浮 300–450ms;遵循 `prefers-reduced-motion`。

## 8. 技术选型建议(Android 原生)

- **UI**:Jetpack Compose + Material 3(动态取色关闭,用上文自定义 tokens)
- **架构**:MVVM;状态用 `StateFlow` + 不可变集合(检索规范:避免 `MutableList` 进 Compose 状态);`LazyColumn` 提供 `key = id`
- **动画**:`animate*AsState` / `AnimatedVisibility`,动画逻辑留在 UI 层不进 ViewModel
- **存储**:Room(单数据库,两表);统计用 SQL `GROUP BY` 按天聚合
- **触觉**:`HapticFeedbackType.LongPress` 轻量反馈;计数成功 `LocalHapticFeedback`
- 无网络权限、无账号体系,APK 体积小

## 9. 里程碑建议

1. W1–2:数据层 + 记录页(计数/撤销/空状态)
2. W3:统计四视图 + 详情
3. W4:管理页 + 弹层 + 深色模式 + 无障碍打磨(可访问标签、触控 48dp、动态字号)
4. 内测:邀请 5–10 位有"反刍思维/抱怨"困扰的用户,验证"打开→记录"路径时长与次日留存
