## 1. 测试环境与方法

- **运行环境**:本地禁缓存服务器 `serve.py`(127.0.0.1:8128,响应头 `Cache-Control: no-store`,排除 HTTP 缓存干扰);浏览器视口 412×892(安卓主流手机尺寸);系统深浅色均可模拟。
- **测试方法**:
  1. 以真实用户操作方式执行(点击、输入、滚动、长流程跨页操作),不注入脚本改变页面状态;
  2. 每个测试点做**双重校验**:DOM/无障碍树只读检查 + 截图视觉确认;
  3. 关键数据逻辑(计数/撤销)加做**数据层断言**:操作前后读取 localStorage 比对记录数;
  4. 全程监控页面错误表现(白屏/错位/报错文案)与壳容器滚动状态(`#app.scrollTop`)。
- **证据留存**:26 张截图,见本文件夹 `截图/` 目录,文件名与测试点编号对应。

### 3.2 回归验证记录(2026-08-31 第二轮)

- **BUG-002**:对真实数据执行 +1,卡片由「今日 1 · 本周 1」同步变为「今日 2 · 本周 2」,撤销后精确还原(记录数 1→2→1),截图 `截图/r2_bug002_week_sync.png`;
- **BUG-003**:计算样式确认 `overflow: clip` 生效;整个弹层混合操作(Playwright 定位点击 + 坐标点击)过程中 `#app.scrollTop` 全程为 0,未再出现壳滚动错乱;
- **BUG-004**:空名称提交触发输入框 `fieldNudge` 抖动动画,弹层保持打开、未写入脏数据,截图 `截图/r2_bug004_empty_nudge.png`;
- **BUG-001**:修复代码已核验(补 `renderHome()`);因当前存储存在使用数据、清空才能复现空状态路径,故未做 GUI 级回归,以代码核验为准。**建议:下次清库时机(如发布前重置)顺带人工复验一次。**

### 3.3 测试注记(非缺陷,体验建议)

1. Snackbar 撤销窗口 5 秒,临近结束时按钮处于滑出动画中,最后一刻点击会落空 → 建议延长至 6~8 秒或滑出期间禁用点击;
2. 年热力图提示「悬停看数值」,触屏无悬停(已有 aria 标签兜底,影响小);
3. 暂停开关的读屏语义为「暂停 xxx + 选中态」,视觉无碍,听感易误会,可改为「启用 xxx」;
4. 统计页念头条形图无点击进详情入口(设计文档提到该路径),建议确认是否有意裁剪。

## 4. 质量评估

- **功能完整性**:V1 范围内功能(计数+撤销、统计四视图、念头管理、归档、备份/恢复/导出/导入、主题、PWA 入口)全部实现且可用;
- **数据可靠性**:所有数据变更点(计数、撤销、删单条、删除念头、归档/恢复、改名、暂停、导入、重置)均即时落盘,多次刷新无丢失;不可逆操作有确认窗且文案精确(列出将删除的记录数);可逆操作均带撤销;
- **文案与设计**:全程无评判性措辞,符合「无羞耻感」产品原则;深浅色主题对比度、布局在手机视口下表现良好;
- **风险提示**:①设计文档中「统计图点击进详情」未实现;②真机专项(PWA 安装/离线、触觉震动、软键盘遮挡、安卓返回键)未在本环境覆盖,上线真机前需补测;③导出 .json 在应用侧触发正常,文件落地需在真机浏览器复核。
